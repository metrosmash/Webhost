## Project structure

- `index.html` is the entry page.
- `pages/` contains the site's HTML pages.
- `css/` contains shared and page-specific stylesheets.
- `js/` contains page scripts.
- `assets/images/` contains site images and the favicon.
- `assets/docs/` is reserved for documents.
